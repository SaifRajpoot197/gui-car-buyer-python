# 💰 Tkinter Money & Car Simulator

A beginner-friendly desktop GUI (Graphical User Interface) application built using Python's built-in **Tkinter** library. Users can interactively add or spend virtual cash and purchase a car with real-time balance updates on the screen.

## ✨ Features
* **Real-Time Balance Display:** Starts with **\$7,000** and updates the display dynamically with every button click.
* **Add Money:** Increase your current balance by **+\$1,000** using the green button.
* **Spend Money:** Deduct **-\$1,000** from your balance using the red button.
* **Buy a Car:** Purchase a car worth **\$5,000** and update the status label to `"Car purchased!"`.
* **Clean Desktop Window:** Configured with an `800x500` window layout and large, readable typography.

## 🛠️ Technologies Used
* **Python 3**
* **Tkinter** (Standard Python GUI library — no extra installation required)

## 🚀 How to Run the Application

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```

2. **Navigate to the project folder:**
   ```bash
   cd YOUR-REPO-NAME
   ```

3. **Run the Python script:**
   ```bash
   python main.py
   ```
   *(Note: Replace `main.py` with your actual Python file name).*
